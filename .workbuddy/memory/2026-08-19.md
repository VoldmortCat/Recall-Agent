# 2026-08-19 错题本 Recall 完整 Web 产品化

## 任务
按线框图 + 详细功能规格，把「Recall AI 智能错题本」从 Vue 旧前端重写为 **React 高保真 Web 产品**，并补齐向量库/OCR/PDF 三大技术栈。

## 技术栈（用户指定）
- 前端：React (Vite)  @ `产品1.0/web`
- 后端：现有 Node.js (Express + Prisma + SQLite)
- 向量数据库：ChromaDB
- 大模型：DeepSeek API（通用 OpenAI 兼容）
- OCR：PaddleOCR-VL
- PDF：ReportLab

## 完成内容
1. **后端增强**
   - schema 新增 `Category`（用户自建分类）/ Mistake 加 `source`、`categoryId`
   - `mistakes` 列表补充返回 ocrText/analysis/source/reviewCount(category)/_count，新增 knowledgePoint、categoryId、masteryStatus 过滤
   - 新增 `categories` 路由（CRUD + 错题计数）
   - 新增 `chromaService.js`（调用 Python 向量服务，不可用时降级关键词相似度）+ `/mistakes/search/similar`
   - `aiService.analyzeMistake` 解析后写入 ChromaDB
   - `export/pdf` 调用 ReportLab 服务，不可用时降级 JSON
   - `stats` 补充 30 天逐日 dailyEntries / dailyReviews
   - chat 路由 mode 跟随运行时配置
2. **Python 服务**（`ai/`）
   - `chroma_db/chroma_service.py`：ChromaDB + 离线哈希 embedding（无需联网下载模型），embed/search/delete/health
   - `pdf/export_pdf.py`：ReportLab 生成错题 PDF（含作答区）
   - `ocr/ocr_service.py`：支持 image_base64，保留 PaddleOCR-VL 真实路径（默认 mock 降级）
3. **React 前端**（`web/`）：设计系统 + 5 页面
   - 页面1 错题集（左分类导航+可新建 / 操作栏 录入·复习·导出·筛选·搜索 / 错题卡片：题目·来源·学科·知识点·AI解析·编辑·删除·复习次数）
   - 页面2 AI答疑（左会话列表+新建 / 右聊天）
   - 页面3 数据看板（指标卡 + recharts 学科分布/掌握度/30天录入·复习趋势）
   - 页面4 API模型设置（模型名/Key/BaseURL，脱敏）
   - 页面5 帮助文档
   - 复用登录态；vite proxy /api→:3000

## 后两轮修复
1. **PDF 导出修复**：前端 `exportApi.pdf` 改为原生 fetch 直接下载 blob，绕过 axios 拦截器，Mistakes 页面 onExport 同步更新
2. **OCR 服务稳定性**：`ocr_service.py` 图片下载失败时优雅返回 mock 数据，不抛 400 异常；Node 端 `performOCR` 失败时仅返回空字符串不阻塞流程
3. **AI 答疑会话持久化**（新增）：
   - schema 新增 `ChatSession`（含 userId/title）和 `ChatMessage`（含 sessionId/role/content）
   - 新增 `chatSessions` 路由：GET 列表 / POST 创建 / GET 详情（含消息） / PUT 改标题 / DELETE 级联删除 / POST :id/messages 发送消息（自动保存用户消息+AI回复+自动更新标题）
   - 前端 Chat.jsx 全部改为从后端持久化读写：加载列表→切换会话时加载详情→发送消息时保存到后端→刷新页面不丢失

## 第三轮修复（掌握状态）
1. **复习后 masteryStatus 写入数据库**：`reviewService.processReview` 现在每次复习后都会更新 `mistake.masteryStatus`（pending→learning→mastered/reviewing），不再只有连续3次才更新
2. **stats 路由区分学习状态**：`mastery` 统计新增 `learning` 和 `reviewing` 分类，不再混入 pending
3. **Dashboard 前端展示**：掌握度分布增加「学习中」「待复习」分类，5 色进度条
4. **PDF 知识图谱兼容**：`export_pdf.py` 处理 `knowledgePoints` JSON 字符串兼容
5. **performOCR URL 修复**：相对路径 `/uploads/xxx` 自动补全为完整 URL，OCR 服务可正常获取图片
6. **日期时区问题**：`createReviewPlan` 和 `review/today` 改用北京时间计算，修复复习列表为空问题
